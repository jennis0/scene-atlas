# Tags

Tags describe what's in an image: its lighting, season, setting and so on. They make [filters](/guide/searching#filters) useful and widen searches through aliases.

Scene Atlas starts you with a built-in set of categories and tags, but they're only a starting point. You can create, rename and delete any category, tag or alias.

## How Images Get Tags

**From names.** At import, words in folder and file names that match a tag or alias become tags: `ForestClearing_Night.jpg` gets *forest* and *night*.

**By hand.** In the [viewer](/guide/gallery#image-viewer), click **+ Tag**, pick a category, then choose or type a value. Remove a tag with the × on its chip. To tag many images at once, use [bulk editing](/guide/groups#bulk-editing).

Every tag belongs to a category with its own colour. Tag chips show only the value; hover to see the category.

## Aliases

Aliases are other words for a tag. If *rainy* is an alias of *rain*, searching for "rainy" finds images tagged *rain*, and a file named `Rainy_Market.jpg` is tagged *rain* on import.

## Managing Tags

Open **Manage Tags** in the top bar. You can:

- create, rename and delete categories, and give each a description, colour and icon;
- add, rename and delete tag values;
- add and remove aliases for each value;
- **Regenerate auto-tags** for the whole library.

Deleting a category or value removes it from every image.

After adding tags or aliases, **Regenerate auto-tags** re-reads every image's names with the new vocabulary. Tags you added by hand are kept.

To start again, **Settings → Library → Reset tags** removes every tag from every image and resets the categories to the Common pack. It can't be undone.

## Built-in Tags

### Categories

The Common pack creates these ten categories. The examples are Common's own tags; other packs add more to the same categories.

| Category | Colour | Examples |
|----------|--------|----------|
| Lighting | Amber | day, night, dusk, dawn, moonlit |
| Season | Orange | spring, summer, autumn, winter |
| Weather | Sky | rain, snow, fog, storm |
| Environment | Emerald | forest, desert, cave, coast, village |
| Features | Stone | temple, bridge, tavern, market, sewer |
| State | Red | ruined, abandoned, overgrown, flooded |
| Theme | Purple | festive (most themes come from the other packs) |
| Population | Cyan | empty, furnished, populated, battle |
| Perspective | Violet | top-down, isometric, side-view |
| Style | Rose | line-art, painted, sketch, pixel-art |

### Tag Packs

Tag packs are ready-made sets of tags and aliases for a genre. Choose them during setup (all are selected to start with), or add more later in **Settings → Tag Packs**.

| Pack | Tags | Adds, for example |
|------|------|-------------------|
| **Common** | 98 | The ten categories above, with tags for any genre |
| **Fantasy** | 22 | fey, underdark, infernal, castle, dungeon, portal, cursed |
| **Sci-Fi** | 16 | starship, station, airlock, alien, steampunk, derelict |
| **Cyberpunk** | 4 | neon, rooftop, terminal, cyberpunk |
| **Horror** | 18 | gothic, eldritch, undead, graveyard, haunted, infested |
| **Historical** | 8 | norse, egyptian, classical, japanese, arabian, western |

Adding a pack merges its tags into your categories without touching tags you've made. A pack can't be removed once added, but you can delete any of its tags yourself.
